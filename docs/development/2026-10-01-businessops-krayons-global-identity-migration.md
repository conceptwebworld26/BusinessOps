## 2. Method

1. Git state checked first: `main` at `e2cf0bb`, equal to `origin/main`, clean working tree.
2. Read-only audit of every tracked file, `dist/businessops/` included. Searched case-insensitively for
   `Prakash Meghani - Concept Web World`, `Concept Web World`, `hello@conceptwebworld.com` and `conceptwebworld.com`.
   No untracked or ignored file contained them.
3. Each occurrence was classified, and only the current ones were changed. The changes were per-file exact string
   replacements with asserted counts, not a global replace.
4. The package was regenerated with `python scripts/build_distribution.py`. No package file was edited by hand.
5. The diff was reviewed after normalising both identities to placeholders: every removed line has an identical
   added line, so nothing other than the identity changed.
