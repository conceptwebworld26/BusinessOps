## 10. Issues discovered

**Three cases cannot be made loadable in Phase 1**, and this is the honest limit of the owner's target state.
`r17-near-miss-market-analysis`, `r18-near-miss-decision-support` and `r19-near-miss-company-analysis` have only
`command_invoked` / `command_not_invoked` graders. The platform requires at least one grader per case, so making
them load would mean either fabricating the trace tool name or substituting a weaker assertion — both forbidden,
and both worse than an honest gap. They carry `platform_status: pending_trace_mapping` and no `graders` key.

**61 of 64 cases are platform-loadable. The suite is not**, so M13-DEF-05 stays open.

Three findings from the contract also shaped the translation, and each is recorded in ADR-0044's implementation
note: `tool_used` matches the tool name with `===` (so the repository's anchored alternations had to be expanded);
JavaScript `RegExp` rejects an inline `(?i)` group (so twelve patterns moved it to `flags`); and the dispatch
tool's trace name is no better established than a command's (so `agent_not_dispatched` became a stricter
trace-content assertion instead of a guessed `tool_used`).

## 11. Decisions made

ADR-0044, accepted. No new ADR: every detail settled here is an implementation consequence of it, recorded in its
dated note rather than as a separate decision.

The judgement worth stating: **an expanded conjunction is not a weakened grader.** One repository assertion over a
tool alternation becomes several platform graders, all of which must pass at `--threshold 1.0`. Where no faithful
expression existed, the grader was marked pending rather than approximated.
