## 4. What the inspection found

- **No SWOT existed** — no module, skill or command. `test_command_registry.py` guarded a
  placeholder name `swot`; `project_plan.md` names the command `/swot-analysis`.
- **The tags already exist as kinds.** `contract.py`: `INTERNAL_KINDS` excludes `SOURCED`,
  `EXTERNAL_KINDS` excludes `FACT`/`CALCULATION`, `RECOMMENDATION` is refused at construction,
  and ADR-0023 refuses an internal `FACT`/`CALCULATION` with no internal footing. So the three
  tags are a pure function of kind; nothing new had to be classified.
- **`interpretation()` records supports only as a note** (`"Rests on: a, b"`) and folds the
  supports' provenance into its own. There is no supports field. A reader therefore has to
  recover supports from that note and check them against the chain.
- **Direct `SynthesisItem` construction bypasses `interpretation()`**, so an `INTERPRETATION`
  with no supports, or a forged note, can enter a set. The consumer must check, not trust.
- **Per-domain origins matter.** `business-health` states e.g. *"Legacy Crates moved …"* from
  both the sales and product analyses; translated under one origin the two share a
  content-addressed id. Under their own origins they are distinct.
- **Synthetic external fixtures grade tier C** (`.example.invalid` is unrecognised) →
  `partially_supported`, `MEDIUM`, `tier_c_only_support`; a *material* tier-C statement grades
  `unsupported`. Both are genuine states a SWOT must handle.

## 6. SWOT consumer design (ADR-0030)

**A point is a placement, never new text.** A placement is `{quadrant, tag, synthesis_id}`; any
other field is refused. The point's text, kind, evidence class, origin, domain, trust, support,
confidence and reasons, materiality, provenance, chain, conflict refs, limitations and caveats
are read from the statement.

**Checks, all fail-closed (`SwotError`, nothing returned):**

| Check | Refuses |
|---|---|
| Input identity | not `type(...) is SynthesisSet`; not strict; empty; any item not graded by `add()` |
| Placement record | not a list of dicts; missing/blank/extra fields; unknown quadrant or tag; non-string id |
| Resolution | id not in the set; id on more than one item |
| Tag | kind has no tag (`ASSUMPTION`, `RECOMMENDATION`); claimed tag ≠ derived tag |
| Evidence | no resolvable provenance; support `unsupported` or `insufficient_evidence` |
| Inference supports | no note; duplicated note; support missing, later than the reading, circular, an `ASSUMPTION`; supports' provenance ≠ the reading's provenance (forged) |
| Side | data-supported outside S/W; externally-sourced outside O/T; inference on a side none of its evidential supports is on |
| Duplication | one statement placed twice, in one quadrant or two |

**Carried whole, never filtered:** every set conflict, every set limitation, the set's
confidence, unresolved dimensions (for footed statements, via `dimension_report()`), caveats,
and `material_not_placed`. Points within a quadrant follow **set order**; `PLACEMENT_NOTE`
states it is not a ranking and that placement requires human review.

## 16. Remaining limitations

1. **Favourable vs unfavourable is not machine-checked.** The engine proves a Strength is
   internal and grounded, not that it is a strength. Placement is model judgement under human
   review, and the result says so.
2. **Supports live in a note.** The reader proves the note agrees with the chain the reading
   actually carries; it cannot prove who wrote the note. A first-class supports field would be
   stronger and is a synthesis-contract change, out of scope.
3. **Point wording is the engine's or the research skill's sentence.** Anything more
   interpretive must first be authored as an interpretation, which the advisory guard may
   over-refuse (ADR-0022's accepted false positives, e.g. "opportunity to").
4. **Identical sentences under one origin are ambiguous** and refused; internal analyses must be
   translated under their own origins (the skill says so).
5. **Tier-C-only external evidence** — every synthetic fixture — can never be a point when
   material, and is `MEDIUM` at best otherwise. Correct, and a practical constraint on SWOTs
   built from unrecognised sources.
6. **The command is model-mediated.** Objects do not persist between tool calls, so the skill's
   flow runs as one script per pass; ids are content-addressed so a candidates pass and a build
   pass agree.
7. **Nothing verified live.** Deterministic and synthetic; R-12 untouched.
