The owner's final governance remediation for M13-DEF-23. Owner decision: a genuine semantic LLM-judge split is neither
`automated_pass` nor `automated_fail`; when the platform cannot establish a deterministic verdict from a semantic
grader, the run is `execution_unavailable` — inconclusive automated evidence, not a product failure; no majority-vote
rule and no pinned judge model. Amend ADR-0039 by the repository's convention, implement the rule in the M13
classifier with tests, keep every historical result and class unchanged, and leave M13.2 `IN PROGRESS`. No evaluation,
product, `lib/`, command, skill, agent, `CLAUDE.md`, `.mcp.json`, ADR-0041/0044/0047/0048 or M13-DEF-13–16 change;
no commit, push or staging.

## 2. Objective

Close M13-DEF-23 with a precise, tested classification rule, without re-scoring history.

## 3. Changes made

1. **Where the verdict became a class.** The platform records one verdict per LLM grader (the judges' majority) and
   folds it into the run's `passed`. `classify_case()` in `tests/unit/test_m13_eval_results.py` took `passed is False`
   on an admissible run as an observed failure, so a split's majority decided the class.
2. **ADR-0049** (accepted, amends ADR-0039 §E.6 in part; ADR-0039 not edited), indexed in `docs/decisions/README.md`.
3. **Classifier.** `judge_votes()` reads a grader's votes from `judgeVotes` or the `judge votes:` explanation;
   `split_graders()` names scored semantic graders whose votes conflict; `established_failure()` recognises a
   deterministic failure or a unanimous semantic failure. In `classify_case()`, an admissible run whose only
   unfavourable evidence is a split is recorded as unavailable, with the grader and votes in the reason. Everything
   else is unchanged, `run_admissibility()` included. ADR-0049 is the default; `SPLIT_AS_RECORDED` names the prior
   rule for confirming stored classes only.
4. **Historical call sites** that confirm stored classes — the case files' binding to the closing evaluation, the pilot
   history, the executed-pilot tests and the split-not-converted test — now name `SPLIT_AS_RECORDED` explicitly.
5. **Documentation:** `eval-suite.md` (*Admitting a result*), `defects.md`, `project_plan.md`, this record.
