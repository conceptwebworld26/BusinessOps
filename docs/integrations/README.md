# Integrations

One file per connector: setup, capabilities exposed, permissions required, limitations.
Capability placeholders and the connector map live in the root `CONNECTORS.md`.
An integration page is written only for a connector admitted under ADR-0038's OD-3, and describes
how to connect it only as its Connector Gate record observed. No connector is admitted (Milestone
12-B shipped an empty registry), so there are no integration pages. HubSpot is a designated future
connector, documented in `CONNECTORS.md`, not here.
